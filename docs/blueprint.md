# **App Name**: AttendEase

## Core Features:

- Manage Profiles: Add, edit, and delete member profiles with fields for Name, Department, and Role/Year.
- Daily Attendance Tracking: A view to mark members present for the current date with a 'Mark Present' button.
- Generate Monthly Reports: Generate an attendance grid for a selected month and year, displaying attendance records for each member.
- Report Export: Export the monthly report as a PDF or CSV file for record-keeping and sharing.

## Style Guidelines:

- Primary color: A shade of deep blue (#1A237E) for main actions and buttons, conveying trust and professionalism.
- Secondary color: A lighter shade of blue (#3F51B5) for interactive elements and highlights.
- Background color: A shade of off-white (#F5F5F5) for a clean and neutral interface.
- Accent color: A bright shade of blue (#29B6F6) for 'Present' status, indicating a positive state; A muted shade of blue (#90CAF9) for 'Absent' status, indicating a negative state.
- Body and headline font: 'Roboto' sans-serif for a clean, modern, and readable user interface.
- Responsive table design with fixed headers to ensure data is accessible on various screen sizes.
- The company logo will be placed in the top-left corner of the website.
- Use simple and clear icons (in shades of blue) to represent actions and status, such as a checkmark for 'Present'.
- Subtle transitions and feedback animations (using shades of blue) to enhance user experience when marking attendance or generating reports.
